# Detection of Seizures Based on EEG Signals: A Machine Learning Approach
Authors: Kaushika Uppu, Miranda Billawala, and Khang Nguyen

***Abstract —*** Epilepsy, a disorder that affects many people
worldwide, is defined by recurring seizures, which can be
monitored and detected with electroencephalography (EEG).
Automating seizure detection is a challenging problem due to the
fact that EEG signals are noisy and complex. In this paper, we
aim to develop a machine learning framework for seizure
detection using the CHB-MIT database that can distinguish
between seizure and non-seizure states. After extracting
time-domain, frequency-domain, and wavelet transform features
to be inputs for the models, we found that SVM had an accuracy
of 61% and a recall of 84%, while XGBoost performed better in
terms of accuracy, 80% and recall, 85%.

***Keywords —*** *electroencephalography, seizure, frequency bands
analysis, classification, discrete wavelet transform, SVM, XGBoost*
